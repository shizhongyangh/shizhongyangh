前端工程师、独立开发者，SZY 创新工作室创始人。做浏览器端的界面与工具：一个跑在网页里的操作系统、给 Minecraft 服主用的备份面板、一个信息学奥赛题库的答案系统。多数项目起于自己用得上，做完顺手开源。

- **在做** — 维护工作室的开源项目，补齐部署文档
- **常用** — HTML、CSS、JavaScript；后台用 PHP 与 MySQL
- **想合作** — 开源工具、Minecraft 生态、前端组件
- **自建** — 云盘、图床、状态监控，以及一台 Minecraft 服务器
