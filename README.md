## 01 / 个人简介

前端工程师、独立开发者，SZY 创新工作室创始人。工作集中于浏览器端的界面与工具开发：网页环境下的操作系统模拟、Minecraft 服务器的运维面板、信息学奥赛题库的答案管理系统。项目多源于实际使用需求，完成后以开源形式发布。

- **工作重点** — 工作室开源项目的维护、发布与部署文档
- **技术方向** — 以 HTML、CSS、JavaScript 构建界面，PHP 与 MySQL 承担服务端
- **协作意向** — 开源工具、Minecraft 生态、前端组件
- **基础设施** — 自建云盘、图床、状态监控与 Minecraft 服务器

**[SZY 创新工作室](https://www.szystudio.cn)** 成立于 2025 年，为非营利技术组织，聚焦开源工具与配套文档，强调功能完整与界面质量并重。
